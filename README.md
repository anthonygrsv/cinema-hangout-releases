# Cinema Hangout — releases

This repository only hosts the **Cinema Hangout launcher** and **game updates** for a private group of
friends. It contains no source code.

**Install:** download `CinemaHangoutLauncher-win-Setup.exe` from the release **launcher** and run it.
The launcher installs and updates the game by itself.

**Releases:**

- `launcher` — the launcher installer and its update feed;
- `channel-alpha`, `channel-experimental` — signed channel descriptions;
- `alpha-0.6.1` and similar — game files of one version. **Do not delete old releases:** later versions
  reuse their files.

Every file is checked by the launcher against a manifest signed by the project owner. Files changed
here without the owner's key are refused.
